# CypherVault Committee Documentation

This directory is reserved for the material delivered to the code-review committee.

```text
docs/
├── report/         # Final/minimized report in DOCX and PDF
├── architecture/   # High-resolution system, database and flow diagrams
├── test-results/   # Unit, integration, security, load and stress-test evidence
└── demo/           # Demo instructions or a recorded-video link
```

## Required checks

- Do not upload private keys, passwords, `.env` files or customer documents.
- Use high-resolution PNG/SVG/PDF figures.
- Keep the repository public for the committee during the evaluation period.
- Verify every command in the root `README.md` on a clean machine or environment.
